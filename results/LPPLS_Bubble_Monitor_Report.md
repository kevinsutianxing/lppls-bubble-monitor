## 一、方法论

### 1.1 LPPLS 模型

论文核心模型——对数周期幂律奇点（Log-Periodic Power Law Singularity）：

```
ln[p(t)] = A + B(tc - t)^β × [1 + C × cos(ω × ln(tc - t) + φ)]
```

| 参数 | 含义 | 约束 |
|------|------|------|
| **A** | 临界时刻 tc 附近的预期对数价格 | A > 0 |
| **B** | 幂律增长幅度 | B < 0 |
| **β** | 幂律指数（控制超指数增长） | 0 < β < 1 |
| **C** | 对数周期振荡幅度 | \|C\| < 1 |
| **ω** | 对数角频率 | ω > 0 |
| **φ** | 相位参数 | 不约束 |
| **tc** | 临界时间（有限时间奇点） | tc > t_end |

### 1.2 统计检验流程

1. **NLLS 校准**：差分进化全局搜索 + L-BFGS-B 有界局部优化，最小化残差平方和
2. **ADF 检验**：对残差进行增广 Dickey-Fuller 检验，残差平稳（ADF < -3.43，即1%显著）→ LPPLS 签名统计显著
3. **迭代稳健性检验**：每次截断开头20个观测值，重复校准+ADF，共10轮，检验 tc 估计的稳定性
4. **风险分级**：综合 ADF 显著性、tc 稳定性、参数合理性

### 1.3 A 股适配

- **前复权处理**：fmdata 存储的是不复权数据，我用 `pct_chg`（涨跌幅）逆向重建前复权价格序列，消除除权除息造成的虚假跳跃
- **分析窗口**：使用近 5 年（~1211 个交易日），兼顾数据量和泡沫时效性
- **风险分级标准**：
  - **HIGH**：ADF@1%显著 + tc 标准差<60天 + 迭代中50%以上1%显著 + 参数合理
  - **MODERATE**：部分条件满足（ADF@1%显著 或 迭代50%+显著）
  - **WATCH**：ADF@5%显著
  - **LOW**：无显著签名

### 2.3 HIGH 风险个股解读

**京东方A（000725）**：β=0.100（极低，强烈超指数特征），tc≈1天（临界时刻已极度临近），迭代 tc_std=8天（非常稳定），10轮迭代全部1%显著。模型认为价格正处于或非常接近有限时间奇点，暗示当前价格加速不可持续。

## 三、重要声明与局限性

### 3.1 LPPLS 不是确定性预测

论文作者 Grobys 明确强调：**tc（临界时间）不是确定性的崩盘日期**，而是市场极度脆弱的阶段。接近 tc 时崩盘概率上升，但具体时机具有随机性，也可能因外生冲击（政策、流动性事件）提前或延后。论文自身也指出 LPPLS 预测的 tc 通常"系统性晚于"真实崩盘时间。

### 3.2 本分析的已知限制

1. **时间窗口选择**：使用近5年数据。论文使用约8.7年（2183天），更长窗口可能捕捉不同泡沫周期
2. **tc 边界效应**：部分股票 tc 估计落在搜索边界（252天=1年上限），说明临界时刻可能超出1年范围，需谨慎解读
3. **A股特殊性**：涨跌停限制（±10%/20%）、政策干预（"国家队"）、T+1 等制度因素可能影响 LPPLS 模型的适用性
4. **β 边界值**：部分股票 β 估计落在 0.1 下界，说明极强超指数特征，但也可能是模型在该数据上的拟合极限
5. **单股噪声**：论文指出个股比指数"噪声更大"，A 股个股尤其如此
6. **前复权精度**：用 pct_chg 重建前复权在极端情况下（停牌复牌、大宗交易折价）可能有微小偏差

### 3.3 投资建议声明

LPPLS 模型是**诊断工具而非交易信号**。它识别的是内生于价格序列的超指数增长模式，不能替代：
- 基本面分析（盈利、估值、现金流）
- 政策面分析（A 股受政策影响极大）
- 流动性与市场结构分析
- 宏观环境判断

**技术状态高分 ≠ 直接卖出**，**无 LPPLS 签名 ≠ 安全买入**。任何投资决策必须结合多维度分析。
